│                                                 │

│  5. Main file: app.py                          │

│                                                 │

## 💻 Manual Commands (if needed)

Open Command Prompt and run:

```bash
cd c:\Users\ASUS\Desktop\student-performance-prediction

git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/student-performance-prediction.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username.

## 🆘 Common Issues

### "git is not recognized"
**Solution:** Download Git from https://git-scm.com/download/win

### "Permission denied"
**Solution:** Use Personal Access Token from GitHub Settings

### "Build failed"
**Solution:** Check requirements.txt and model files exist
